Про нас

Наша місія — забезпечити кожного клієнта надійною та швидкою технікою для навчання, роботи та розваг. Як писав журнал Комп'ютерний світ , ми є лідерами у своєму регіоні.

    Host: localhost;
    Port: 8080;
}

Для запуску використовуйте команду: npm start
